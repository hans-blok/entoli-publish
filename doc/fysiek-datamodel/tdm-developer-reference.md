# Technical Data Model — developer reference

Written for: developers who build on, query or load the Entoli PostgreSQL database.

This document describes every table of the current PostgreSQL Technical Data Models (TDM), grouped by Logical Instance. The TDM JSON files are the source for the physical structure. The Logical Data Models (LDM) are the source for the logical names of entities and relationships. The table definitions ("One row") are summaries written for this reference; the LDM definitions remain authoritative. This document is not generated by a repository script and is not updated automatically: when a TDM changes, this document must be revised.

## How to read this document

- **Required** `yes` means the column is `NOT NULL`.
- **Key** `PK` marks a primary key column and `FK` a column of a foreign key.
- **Logical reference** marks a code column that refers to a row in another Logical Instance. There is no foreign key behind it: PostgreSQL does not enforce it. The application keeps it consistent.
- Constraint names are built from the table code (`PK_<table>`, `FK_<child>_<parent>_<nn>`, `UC_<table>_<nn>`, `CK_<table>_<nn>`); see `physical-naming-convention.md` (not published on this site).
- The relationship named with a foreign key or a logical reference is the LDM relationship that the TDM records as its source.
- Foreign keys use `ON DELETE NO ACTION` and `ON UPDATE NO ACTION` unless stated otherwise.

**Example rows are illustrative.** They are not database content and not prescribed seed data. One scenario runs through all tables: the NIAM Analyst surveys sources, after which the Logical Data Modeller derives a logical data model. Rows that refer to each other use the same keys, also across Logical Instances. Surrogate key values are illustrative; the database assigns them. Codes of reference tables are taken from the LDM positions where the LDM defines them. Where no value follows from the sources, a recognisable fictitious value is used and a note says so. Long text is shortened with `…`; `↵` marks a line break.
