# Data Modelling — LLM-constraints

De regels die gelden voor een agent die met datamodellen werkt, zoals ze in de
canon zijn vastgelegd. Het bestand bevat twee regelsets met een verschillend
doel: de diagnostische `DAMA-*`-regels leggen vast welke kennis de agent geacht
wordt te bezitten en correct toe te passen, de operationele `LDM-*`-regels sturen
de afleiding van een logisch datamodel uit een aangeleverd conceptueel of
informatiemodel.
