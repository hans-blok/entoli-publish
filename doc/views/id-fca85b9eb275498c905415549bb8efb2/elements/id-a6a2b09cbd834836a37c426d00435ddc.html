core rule ()
DEFINITIE Een Core Rule (Kernregel) is een regel die een Execution Regime governt en daarmee een algemene gedragsbeperking vastlegt die voortvloeit uit de betekenis van dat regime. DOEL De betekenis van een Execution Regime vertalen naar expliciete regels waarmee kan worden bewaakt dat gedrag binnen de grenzen van dat regime blijft. LEIDENDE VRAAG Welke regel moet gelden om uitvoering in overeenstemming te houden met dit Execution Regime? RELATIES Een Core Rule governs precies één Execution Regime. Een Execution Regime kan door nul of meer Core Rules worden governed. Dit is de relatie die het huidige model expliciet ondersteunt. De verdere positie van Core Rule binnen de nieuwe Entoli Rule → Normative Rule / Operational Rule-structuur is op basis van de huidige bron niet voldoende eenduidig vast te stellen. BEPERKINGEN Een Core Rule is niet hetzelfde als een Canon Rule, Entoli Agent Rule of Entoli Agent Intent Rule. Op basis van de huidige bron kan nog niet verantwoord worden gesteld of Core Rule een Normative Rule, Operational Rule of een andere specialisatie van Entoli Rule is. Een Core Rule moet daarom niet op basis van naam alleen als "fundamentelere" of "hogere" regel worden geïnterpreteerd. INVARIANTEN Iedere Core Rule governt precies één Execution Regime. Een Core Rule begrenst gedrag vanuit de betekenis van het betreffende Execution Regime.
