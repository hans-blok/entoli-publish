normative rule ()
DEFINITIE Een Normative Rule (Normatieve regel) is een Rule die vastlegt wat binnen een bepaalde ontwerpgrondslag, verantwoordelijkheid of scope moet gelden, zonder zelf voor te schrijven welke concrete handeling tijdens een Execution moet worden uitgevoerd. DOEL Duurzame normen expliciet en traceerbaar vastleggen, zodat zij als grondslag kunnen dienen voor verdere concretisering en operationalisering zonder dat de oorspronkelijke norm bij iedere Execution opnieuw hoeft te worden geïnterpreteerd. LEIDENDE VRAAG Wat moet binnen deze scope gelden, onafhankelijk van de concrete handeling waarmee daaraan uitvoering wordt gegeven? RELATIES * **specialisation-of** → `Rule` * Kan door een meer specifieke **Normative Rule** worden geconcretiseerd. * Kan door één of meer **Operational Rules** worden geoperationaliseerd. * Een **Canon Rule** is een Normative Rule binnen de Canon. * Een **Entoli Agent Rule** is een Normative Rule die geldt voor een specifieke Entoli Agent. BEPERKINGEN * Een Normative Rule schrijft niet de concrete uitvoering van een specifieke Agent Intent voor. * Een Normative Rule is niet rechtstreeks afhankelijk van één Execution. * Een concretisering mag de betekenis van de bovenliggende Normative Rule verfijnen of de interpretatieruimte verkleinen, maar niet tegenspreken. * Een Normative Rule hoeft niet rechtstreeks onderdeel te zijn van een Instruction Set. INVARIANTEN * Een Normative Rule beschrijft **wat moet gelden**, niet **wat tijdens een specifieke handeling moet worden gedaan**. * Een Normative Rule behoudt zijn normatieve betekenis wanneer hij verder wordt geconcretiseerd.* Een Operational Rule die uit een Normative Rule voortkomt, mag niet strijdig zijn met die Normative Rule.
