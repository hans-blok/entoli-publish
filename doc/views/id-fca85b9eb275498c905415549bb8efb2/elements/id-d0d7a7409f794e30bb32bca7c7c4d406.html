entoli agent rule ()
DEFINITIE Een Entoli Agent Rule is een normatieve regel voor precies één Entoli Agent die een voor die Agent toepasselijke Canon Rule concretiseert binnen de verantwoordelijkheid en boundary van die Agent. De Entoli Agent Rule vertaalt daarmee canonieke normering naar agent-specifieke normering zonder het normatieve gezag of de betekenis van de Canon Rule te wijzigen. DOEL Expliciet en herleidbaar vastleggen hoe een Canon Rule doorwerkt op één specifieke Entoli Agent, zodat canonieke normering niet impliciet hoeft te worden geïnterpreteerd bij iedere uitvoering en aantoonbaar blijft welke agent-specifieke regel op welke canonieke regel berust. LEIDENDE VRAAG Hoe wordt deze Canon Rule normatief van toepassing gemaakt op deze specifieke Entoli Agent? RELATIES Een Entoli Agent Rule behoort tot precies één Entoli Agent. Een Entoli Agent kan nul of meer Entoli Agent Rules hebben. Een Entoli Agent Rule is gekoppeld aan precies één Canon Rule die de canonieke normatieve grondslag vormt. Een Canon Rule kan door nul of meer Entoli Agent Rules voor verschillende Entoli Agents worden geconcretiseerd. BEPERKINGEN Een Entoli Agent Rule is niet de Canon Rule zelf: de Canon Rule ontleent haar gezag aan de Canon, terwijl de Entoli Agent Rule de toepassing daarvan voor één Entoli Agent vastlegt. Zij is ook geen Entoli Agent Intent Rule: die normeert één specifieke Agent Intent. De Entoli Agent Rule mag de betekenis of het geldigheidsbereik van haar Canon Rule niet zelfstandig wijzigen en mag daarmee niet in tegenspraak zijn. Dit sluit aan bij de bestaande canonieke invariant dat Agent Rules een toepasselijke Canon Rule niet mogen tegenspreken. INVARIANTEN Iedere Entoli Agent Rule behoort tot precies één Entoli Agent en heeft precies één Canon Rule als normatieve grondslag. Zij blijft binnen de boundary van haar Entoli Agent en binnen het geldigheidsbereik van de gekoppelde Canon Rule. Zij mag die Canon Rule concretiseren, maar nooit verzwakken, overschrijven of tegenspreken.
