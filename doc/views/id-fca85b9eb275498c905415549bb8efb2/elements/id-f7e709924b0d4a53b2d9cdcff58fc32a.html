DEFINITIE Een Entoli Agent Intent Rule (Entoli Agent Intent-regel) is een Operational Rule die voor precies één Entoli Agent Intent vastlegt welk gedrag tijdens de uitvoering van die Intent moet worden uitgevoerd, nagelaten of onder bepaalde voorwaarden is toegestaan. DOEL Normatieve regels operationaliseren tot regels die voldoende concreet zijn om het gedrag van een LLM tijdens de uitvoering van één specifieke Agent Intent rechtstreeks te sturen, zonder dat het LLM de onderliggende norm eerst zelfstandig hoeft te interpreteren. LEIDENDE VRAAG Wat moet tijdens de uitvoering van deze specifieke Entoli Agent Intent concreet worden gedaan of nagelaten om overeenkomstig de geldende norm te handelen? RELATIES Entoli Agent Intent Rule is een specialisatie van Operational Rule. Een Normative Rule wordt geoperationaliseerd door één of meer Entoli Agent Intent Rules. Een Entoli Agent Intent Rule constrains precies één Agent Intent. Een Operational Rule kan als toepasselijke regel in een Instruction Set worden opgenomen. BEPERKINGEN Een Entoli Agent Intent Rule is geen Normative Rule. Zij introduceert niet zelfstandig de norm waaraan moet worden voldaan, maar operationaliseert bestaande normering voor één concrete capability. Een Entoli Agent Intent Rule is geen Entoli Agent Rule. Een Entoli Agent Rule concretiseert normering voor de verantwoordelijkheid en boundary van een Agent; een Entoli Agent Intent Rule specificeert het daadwerkelijk verwachte gedrag binnen één Agent Intent. Een Entoli Agent Intent Rule mag niet vereisen dat het uitvoerende LLM eerst zelf de bovenliggende norm interpreteert om te bepalen welk gedrag wordt verwacht. INVARIANTEN Iedere Entoli Agent Intent Rule geldt voor precies één Agent Intent. Iedere Entoli Agent Intent Rule is voldoende concreet om als uitvoeringsinstructie aan een LLM te kunnen worden aangeboden. Wanneer een Entoli Agent Intent Rule een Normative Rule operationaliseert, blijft die normatieve herkomst traceerbaar. Een Entoli Agent Intent Rule mag de Normative Rule die zij operationaliseert niet tegenspreken.
