core rule ()
DEFINITIE Een Core Rule (Kernregel) is een Operational Rule die afkomstig is uit de canon, niet door de gebruiker wijzigbaar is, en die de structurele en gedragsmatige integriteit van precies één Execution Regime waarborgt. DOEL Een canoniek gezaghebbende, voor de gebruiker onveranderlijke waarborg vastleggen die de integriteit van een Execution Regime beschermt, onafhankelijk van en niet noodzakelijk zichtbaar binnen enig Instruction Set. LEIDENDE VRAAG Welke canoniek gezaghebbende waarborg beschermt de integriteit van dit Execution Regime? RELATIES Core Rule is een specialisatie van Operational Rule, en daarmee via Operational Rule een Entoli Rule. Een directe specialisatie naar Entoli Rule wordt niet gemodelleerd: die zou transitief redundant zijn. Een Core Rule governt precies één Execution Regime; een Execution Regime kan door nul of meer Core Rules worden gegovernd. BEPERKINGEN Een Core Rule is geen Canon Rule. Een Canon Rule is een Normative Rule die haar gezag aan de Canon ontleent en vastlegt wat moet gelden; een Core Rule is een Operational Rule die voorschrijft welk gedrag binnen de grenzen van een Execution Regime moet blijven. Een Core Rule is evenmin een Entoli Agent Rule of een Entoli Agent Intent Rule. De eerste is normatief en gebonden aan precies één Agent; de tweede operationaliseert normering voor precies één Agent Intent. Een Core Rule is aan geen van beide gebonden, maar aan één Execution Regime. Een Core Rule mag niet op grond van haar naam alleen als fundamenteler of hoger dan andere regels worden gelezen. INVARIANTEN Een Core Rule is voor de gebruiker te allen tijde onveranderlijk. Iedere Core Rule is herleidbaar tot precies één Execution Regime waarvan zij de integriteit waarborgt. Voorbeelden: - Preserving introduceert geen nieuwe betekenis — Core Rule die de integriteit van de positie Preserving binnen Synthesis Regime bewaakt. - Input-bound gebruikt alleen expliciet aangeboden bronnen — Core Rule die de toegestane bronruimte van een Source Regime bewaakt.
