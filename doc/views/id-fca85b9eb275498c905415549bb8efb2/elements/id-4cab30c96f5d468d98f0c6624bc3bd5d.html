DEFINITIE Execution Regime is de verzamelnaam voor de classificatie-assen die gezamenlijk bepalen wat een Agent Intent mag doen: Source Regime (welke kennis toegankelijk is), Synthesis Regime (welke betekenistransformatie is toegestaan), Task Regime (welke bewerkings- en uitvoervorm de stap heeft) en Reasoning Regime (hoeveel cognitieve vrijheid het LLM heeft). DOEL Voor iedere Agent Intent in één samenhangend geheel vastleggen welke combinatie van regimes van toepassing is, zodat deze onafhankelijk gedeclareerde assen gezamenlijk als één governance-mechanisme kunnen worden aangesproken en gecontroleerd. LEIDENDE VRAAG Welke combinatie van bron-, synthese-, taak- en redeneerregime governt deze Agent Intent? SAMENSTELLING Execution Regime kent op dit moment vier specialisaties: Source Regime, Synthesis Regime, Task Regime en Reasoning Regime. Het aantal specialisaties is een eigenschap van de subtypestructuur en wordt niet als multipliciteit op een relatie vastgelegd; het kan veranderen zonder dat enige relatie hoeft te worden aangepast. RELATIES Source Regime, Synthesis Regime, Task Regime en Reasoning Regime zijn specialisaties van Execution Regime. Een Agent Intent wordt gegoverneerd door één of meer Execution Regimes; een Execution Regime governt nul of meer Agent Intents. Een Core Rule governt precies één Execution Regime; een Execution Regime kan door nul of meer Core Rules worden gegovernd. BEPERKINGEN De specialisaties van Execution Regime zijn onderling orthogonaal: geen enkele specialisatie is afleidbaar uit, of impliceert, een waarde van de andere. Execution Regime is geen enkelvoudige schaal waarop de specialisaties inwisselbare posities zijn; elke specialisatie beantwoordt een eigen, onafhankelijke vraag. Het aantal specialisaties is geen betekenis van de relatie tussen Agent Intent en Execution Regime: die relatie legt vast dát een Agent Intent door Execution Regimes wordt gegoverneerd, niet door hoeveel. INVARIANTEN Iedere Agent Intent declareert precies één positie op elke specialisatie van Execution Regime die op die Agent Intent van toepassing is, en wordt daarmee door ten minste één Execution Regime gegoverneerd. Deze invariant blijft gelden wanneer een specialisatie wordt toegevoegd of vervalt.
