operational context ()
DEFINITIE Een Operational Context is een klantgebonden, persistente operationele omgeving waarbinnen Executions plaatsvinden en waarin de voor die omgeving relevante operationele toestand wordt behouden. De context is onafhankelijk van de technische applicaties, systemen of workspaces waarmee deze omgeving wordt gerealiseerd. DOEL Het afbakenen van de operationele omgeving waarbinnen Entoli voor een specifieke Customer Context wordt gebruikt. Hierdoor kunnen binnen één Customer Context meerdere van elkaar gescheiden operationele omgevingen bestaan, ieder met hun eigen uitvoering en toestand. LEIDENDE VRAAG Binnen welke klantgebonden operationele omgeving vindt deze Execution plaats? RELATIES Een Customer Context heeft één of meer Operational Contexts. Iedere Operational Context behoort tot precies één Customer Context. Een Operational Context is de context voor nul of meer Executions. Iedere Execution vindt plaats binnen precies één Operational Context. BEPERKINGEN Een Operational Context is geen Customer Context, Agent Package, Execution, applicatie, IT-systeem of technische workspace. Een tenant workspace kan een technische realisatie van een Operational Context zijn, maar definieert het concept niet. De Operational Context bepaalt evenmin welke Agent Packages beschikbaar zijn; het gebruik daarvan is afleidbaar via de Executions die binnen de Operational Context plaatsvinden. Dit sluit aan op de brondeﬁnitie waarin Operational Context expliciet als operationele container en niet als software- of systeemgrens wordt onderscheiden. INVARIANTEN Iedere Operational Context behoort tot precies één Customer Context. Iedere Execution vindt plaats binnen precies één Operational Context. De operationele context van een Instruction Set wordt afgeleid van de Execution die door die Instruction Set wordt geïnstrueerd; de Instruction Set heeft daarom geen zelfstandige Operational Context nodig.
