Reasoning mode ()
Reasning mode is a classification axis that gates whether an agent's work is subject to the content-governance model — the combination of **Source-regime**, **Synthesis-regime**, and **Task Mode** — based on one question: does this step require an LLM to reason at all. Leading question Does this agent-intent require an LLM to reason about meaning, or does it execute by fixed procedure with no reasoning? **Provenance**: replaces the retired **Mode of operation** concept (see Appendix — Deprecated terms). Mode of operation's three positions (Content, Representation-transforming, Conditional) answered three loosely related questions under one label; Determinism asks exactly one, and collapses the two non-content positions — both of which were, on inspection, already mechanical/rule-based rather than meaning-blind-with-exceptions — into a single **Deterministic** position. See `temp/claude-code-plans/plan-execution-nature.md` for the full migration record. ### Characteristics ⭐ - One of two **agent-intent** classification axes (alongside **Development phase**, which is agent-level — see Development phase, Explanation) - Is a **gate**, not a scale: each position determines *whether* Source-regime/Synthesis-regime/Task Mode apply, not *how much* meaning-transformation is permitted - Independent of other axes, including **Execution Strategy**: Execution Strategy governs how a *sequence* of steps progresses and has no vocabulary for whether one step is mechanical; Determinism governs whether one step requires reasoning at all and has no vocabulary for sequencing. A single Orchestration Specification may freely compose Deterministic and Cognitive steps under any Execution Strategy — neither axis may be inferred from, or used to infer, the other (see Execution Strategy, Relationships) - A **Deterministic** agent-intent is realised as a script, never as an LLM call; a **Cognitive** agent-intent is realised as an LLM call with full content-governance applying ### What it is not ❌ - Not a meaning-transformation scale (that is **Synthesis-regime**) - Not a task-shape classification (that is **Task Mode**) - Not a progression-logic constraint (that is **Execution Strategy**) — see Characteristics - Not redundant with Synthesis-regime or Task Mode: its positions gate whether those two axes (and Source-regime) apply, they do not duplicate a value on either axis's scale ### Synonyms ��️ - Cognitive gate ### Explanation �� Determinism distinguishes agent-intents that require an LLM to reason from work that is realised as a script and never invokes an LLM at all — mechanical representation-conversion and rule-based condition/hygiene checks alike.
