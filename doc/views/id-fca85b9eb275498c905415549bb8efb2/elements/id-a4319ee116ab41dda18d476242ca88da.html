DEFINITIE Een Instruction Set is de samengestelde, execution-specifieke set van instructies en context die bepaalt op basis waarvan een Execution wordt uitgevoerd. DOEL Het samenbrengen van alle normatieve, semantische en overgedragen context die voor één concrete Execution van toepassing is, zodat de Execution vanuit een expliciete en reproduceerbare instructiebasis wordt uitgevoerd. LEIDENDE VRAAG Welke instructies en context moeten voor deze Execution beschikbaar zijn? SAMENSTELLING Een Instruction Set kan toepasselijke Rules, relevante Elements en Relationships uit het Semantic Model en een Handoff uit een voorafgaande Execution bevatten. De Instruction Set vormt daarmee geen zelfstandig Semantic Model, maar een voor de Execution samengestelde selectie van relevante betekenis, regels en context. RELATIES Een Instruction Set wordt samengesteld voor één Agent Intent. Een Agent Intent kan de samenstelling van nul of meerdere Instruction Sets initiëren. Een Instruction Set bevat één of meer toepasselijke Rules en kan relevante Elements, Relationships en Handoffs bevatten. Een Instruction Set instrueert precies één Execution. Iedere Execution wordt door precies één Instruction Set geïnstrueerd. BEPERKINGEN Een Instruction Set introduceert geen nieuwe canonieke betekenis. Opgenomen Elements en Relationships blijven afkomstig uit het Semantic Model en opgenomen Rules behouden hun oorspronkelijke normatieve betekenis. Een Handoff brengt context uit een voorafgaande Execution over, maar creëert geen directe relatie tussen die voorafgaande en de volgende Execution. INVARIANTEN Iedere Execution wordt geïnstrueerd door precies één Instruction Set. Alle opgenomen semantische elementen en relaties moeten herleidbaar zijn tot hun Semantic Model. Alle opgenomen Rules moeten voor de betreffende Execution van toepassing zijn. Een opgenomen Handoff moet geproduceerd zijn door een eerdere Execution.
