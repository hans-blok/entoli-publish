DEFINITIE Een Template is een herbruikbare specificatie van de vorm waarin een Artifact van een bepaald Artifact Type kan worden vastgelegd. DOEL Maakt de vorm van professionele werkproducten expliciet en herbruikbaar, zodat Artifacts van hetzelfde Artifact Type op een consistente manier kunnen worden vastgelegd. LEIDENDE VRAAG Welke vorm kan of moet worden gebruikt om een Artifact van dit Artifact Type vast te leggen? RELATIES Een Template specificeert vorm voor precies één Artifact Type. Een Artifact Type kan door nul of meer Templates van vorm worden voorzien. BEPERKINGEN Een Template is geen Artifact en vertegenwoordigt geen concrete instantie van een werkproduct. Een Template is geen Artifact Type en definieert niet wat voor soort werkproduct een Artifact is. Een Template definieert niet de betekenis van het Artifact Type waarvoor het vorm specificeert. Een Template hoeft in het conceptuele model niet rechtstreeks aan een concreet Artifact gerelateerd te zijn. INVARIANTEN Een Template specificeert altijd vorm voor precies één Artifact Type. Als een Template wordt toegepast op een Artifact, moet het Artifact geclassificeerd zijn door het Artifact Type waarvoor het Template vorm specificeert.
