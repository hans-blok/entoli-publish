entoli agent intent rule ()
DEFINITIE Een Entoli Agent Intent Rule is een normatieve regel voor precies één Agent Intent van een Entoli Agent, die vastlegt hoe normering specifiek doorwerkt op de uitvoering van die Intent. Zij specificeert daarmee gedrag dat uitsluitend voor die aanroepbare capability geldt en niet automatisch voor andere Agent Intents van dezelfde Entoli Agent. DOEL Normering kunnen verfijnen tot het niveau waarop daadwerkelijk een specifieke capability wordt aangeroepen, zonder daarvoor de Entoli Agent of zijn andere Agent Intents te hoeven specialiseren. Daarmee kan iedere Intent zijn eigen expliciete operationele normering hebben terwijl de gedeelde normatieve structuur op agentniveau behouden blijft. LEIDENDE VRAAG Welke specifieke norm geldt voor de uitvoering van deze Agent Intent? RELATIES Een Entoli Agent Intent Rule behoort tot precies één Agent Intent. Een Agent Intent kan nul of meer Entoli Agent Intent Rules hebben. De Agent Intent behoort op zijn beurt tot precies één Entoli Agent. Daarmee bevindt de Entoli Agent Intent Rule zich normatief onder de regels die voor de Entoli Agent als geheel gelden. Het bestaande canonieke begrip Agent Intent Rule bevestigt deze intent-specifieke reikwijdte en staat toe dat regels tussen Intents van dezelfde Agent verschillen. BEPERKINGEN Een Entoli Agent Intent Rule is geen Entoli Agent Rule: zij geldt niet voor alle Intents van de Entoli Agent, maar uitsluitend voor één Agent Intent. Zij mag de voor haar Agent geldende normering niet overschrijven. Evenmin verkrijgt zij zelfstandig canoniek gezag; canonieke autoriteit blijft bij de Canon Rule. De bestaande canon positioneert Agent Intent Rules nadrukkelijk als intent-specifiek en zonder eigen canonieke invariantstatus. INVARIANTEN Iedere Entoli Agent Intent Rule behoort tot precies één Agent Intent. Haar geldigheidsbereik overschrijdt die Intent niet. Zij mag specifieke normering toevoegen of concretiseren, maar mag geen voor de bovenliggende Entoli Agent geldende regel of toepasselijke Canon Rule tegenspreken.
