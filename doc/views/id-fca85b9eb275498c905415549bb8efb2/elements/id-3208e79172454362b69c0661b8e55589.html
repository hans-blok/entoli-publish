MODEL ASSIGNMENT (MODELTOEWIJZING) DEFINITIE Een Model Assignment legt vast welk LLM Model, via welk LLM Account en met welke modelparameters wordt gebruikt voor een Execution wanneer de betreffende toewijzing van toepassing is. DOEL Maakt de keuze en configuratie van een LLM voor uitvoering expliciet, zonder deze vast te leggen in de Agent, Agent Intent of het LLM Model zelf. Hierdoor kan hetzelfde LLM Model voor verschillende soorten werk met verschillende instellingen worden ingezet. LEIDENDE VRAAG Welk LLM Model moet via welk LLM Account en met welke instellingen voor deze Execution worden gebruikt? VOORBEELDEN Default Model: GPT-5.4 Temperature: 0.2 Toepassing: standaard wanneer geen specifiekere Model Assignment van toepassing is. Architecture Exploration Model: GPT-5.4 Temperature: 0.7 Development Phase: Exploration Toepassing: verkennend werk waarbij variatie en het onderzoeken van alternatieven gewenst zijn. Architecture Specification Model: GPT-5.4 Temperature: 0.2 Development Phase: Specification Toepassing: specificerend werk waarbij consistentie en nauwkeurigheid belangrijk zijn. Architecture Review Model: GPT-5.4 Temperature: 0.1 Development Phase: Testing Toepassing: toetsend werk waarbij reproduceerbaarheid en strikte beoordeling gewenst zijn. Fast Operational Task Model: GPT-5.4-mini Temperature: 0.1 Toepassing: relatief eenvoudige uitvoeringen waarbij snelheid en kosten zwaarder wegen. De modelnamen en temperaturewaarden hierboven zijn voorbeelden, geen canonieke voorgeschreven waarden. RELATIES Een Model Assignment selecteert precies één LLM Model. Een Model Assignment gebruikt precies één LLM Account. Een Model Assignment kan van toepassing zijn op een Development Phase. Een Model Assignment zonder specifieke Development Phase kan als standaardtoewijzing fungeren. Een Model Assignment kan door nul of meer Executions worden gebruikt. Iedere Execution gebruikt precies één Model Assignment. CONFIGURATIE Een Model Assignment bevat de modelparameters die voor de uitvoering gelden. Temperature is zo'n parameter en bepaalt de mate van variatie in de gegenereerde output. Andere modelparameters kunnen worden toegevoegd wanneer deze conceptueel relevant worden voor modelselectie en uitvoering. INVARIANTEN Het geselecteerde LLM Model en het gebruikte LLM Account moeten compatibel zijn met dezelfde LLM Provider. Het gebruikte LLM Account moet beschikbaar zijn binnen de Customer Context waarin de Execution plaatsvindt. Voor iedere Execution moet eenduidig één toepasselijke Model Assignment kunnen worden bepaald. Een specifieke Model Assignment heeft voorrang op de standaardtoewijzing wanneer aan de toepassingsvoorwaarde wordt voldaan.
