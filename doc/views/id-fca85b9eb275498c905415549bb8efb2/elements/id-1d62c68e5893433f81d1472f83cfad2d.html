knowledge specification ()
Definition Knowledge Specification — An explicit specification of the knowledge from a Knowledge Domain that must be represented and governed for a defined purpose. De Knowledge Specification bepaalt daarmee welke kennis uit het domein expliciet gemaakt moet worden en met welke bedoeling. Het is dus niet de kennis zelf en ook nog niet noodzakelijk de concrete Canon. Bijvoorbeeld: Knowledge Domain Data Modelling ↓ specified by Knowledge Specification Entoli Logical Data Modelling De Knowledge Specification kan dan verlangen dat onder andere expliciet wordt gemaakt: What is an Entity? What is a Reference Entity? What is a Relationship? What is Cardinality? How are entities identified? How are relationships represented? Which modelling rules are normative? De Canon realiseert vervolgens die specification door de daadwerkelijke concepten, relaties en rules vast te leggen.
