Definition Knowledge Domain — A bounded area of knowledge, concepts, relationships, practices, and terminology concerning a coherent subject of interest. Een Knowledge Domain bepaalt dus primair waarover de kennis gaat. Het zegt nog niet welke interpretatie Entoli daarvan canoniek hanteert. Voorbeeld Agent Development kan een Knowledge Domain zijn. Daarbinnen vallen bijvoorbeeld onderwerpen als: agent; intent; boundary; capability; orchestration; semantic scope; agent package. Het domein kan groter zijn dan wat je uiteindelijk in een specifieke canon vastlegt. Niet alles wat over Agent Development bekend is, hoeft onderdeel te zijn van de canon. Een tweede voorbeeld: Data Modelling is een Knowledge Domain waarin begrippen zoals Entity, Attribute, Relationship, Cardinality en Logical Data Model relevant zijn.
