DEFINITIE Een Universal Rule is een specifieke operationele regel die bij iedere uitvoering van een Agent Intent van toepassing is, onafhankelijk van het gekozen uitvoeringsregime. Het Large Language Model interpreteert de regel en past haar toe wanneer de beschreven voorwaarde optreedt. DOEL Concreet gedrag vastleggen dat voor alle Agent Intents geldt, zonder het per regime of Agent Intent opnieuw te specificeren. LEIDENDE VRAAG Welk concreet gedrag moet het Large Language Model bij iedere uitvoering toepassen wanneer de beschreven voorwaarde optreedt? RELATIES Een Universal Rule wordt bij het samenstellen van iedere Instruction Set betrokken. Zij heeft geen relatie met een uitvoeringsregime nodig om van toepassing te zijn. Haar grondslag ligt in de constitutie; de constitutie blijft buiten het datamodel. BEPERKINGEN Een Universal Rule is een operationele uitwerking, geen algemene constitutieregel en geen Regime Rule. Universele toepasselijkheid betekent niet dat de voorgeschreven handeling bij iedere uitvoering plaatsvindt. INVARIANTEN Iedere actuele Universal Rule wordt in iedere Instruction Set opgenomen. Haar toepasselijkheid hangt niet af van Agent, Agent Intent of uitvoeringsregime. Het Large Language Model beoordeelt de beschreven voorwaarde en volgt de regel wanneer die voorwaarde is vervuld.
