artifact type ()
DEFINITIE Een Artifact Type definieert een herkenbare soort professioneel werkproduct en de betekenis die Artifacts van dat type gemeenschappelijk hebben. DOEL Maakt het mogelijk om concrete Artifacts naar hun betekenis en functie als werkproduct te classificeren, onafhankelijk van hun concrete inhoud of vorm. LEIDENDE VRAAG Wat voor soort professioneel werkproduct is dit Artifact? RELATIES Een Artifact Type classificeert nul of meer Artifacts. Een Artifact behoort tot precies één Artifact Type. Een Artifact Type kan door nul of meer Templates van vorm worden voorzien. Een Template specificeert vorm voor precies één Artifact Type. BEPERKINGEN Een Artifact Type is geen concreet Artifact. Een Artifact Type is geen Template en schrijft daarom niet zelf de vorm van een Artifact voor. Een Artifact Type beschrijft het soort werkproduct en niet een specifieke representatie of uitvoering daarvan. INVARIANTEN Ieder Artifact wordt door precies één Artifact Type geclassificeerd. Een Template die van toepassing is op een Artifact moet vorm specificeren voor het Artifact Type dat dit Artifact classificeert.
