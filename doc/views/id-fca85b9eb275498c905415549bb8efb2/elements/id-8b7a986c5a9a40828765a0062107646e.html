DEFINITIE Een classificatie-as die aangeeft in welke fase van de totstandkoming van werk een Agent intervenieert. De as positioneert het werk in de keten van eerste verkenning tot operationalisering. DOEL Maakt expliciet waar in het ontwikkelproces een Agent opereert, onafhankelijk van het soort handeling dat de Agent uitvoert. Dit ondersteunt ordening, bestuurbaarheid en traceerbaarheid. LEIDENDE VRAAG Waar in de totstandkoming van het werk vindt de interventie plaats? WAARDEN Exploration (Verkenning) Ordering (Ordening) Specification (Specificatie) Realisation (Realisatie) Testing (Toetsing) Registering (Registratie) Operationalisation (Operationalisering) RELATIES Development Phase classificeert een Agent. De afzonderlijke waarden zijn posities binnen Development Phase. BEPERKINGEN Development Phase classificeert de fase van interventie, niet het type activiteit, het outputgedrag of een technische implementatiestap. De posities vormen geen waardeschaal: een latere fase is niet belangrijker dan een eerdere fase.
