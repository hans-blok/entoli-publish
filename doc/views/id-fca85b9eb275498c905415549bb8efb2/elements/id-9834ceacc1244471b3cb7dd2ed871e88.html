model assignment ()
Het vermogen om te bepalen welk beschikbaar LLM Model, met welke modelparameters, voor een Execution wordt ingezet. Model Assignment maakt de keuze van het uitvoerende model expliciet en configureerbaar, zodat dezelfde agentfunctionaliteit en orchestratie met verschillende modellen kan worden uitgevoerd zonder de definitie daarvan te wijzigen.
