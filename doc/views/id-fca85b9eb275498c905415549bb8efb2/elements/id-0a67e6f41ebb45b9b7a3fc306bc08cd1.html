orchestration specification ()
DEFINITIE Een Orchestration Specification is de binnen een Operational Context vastgelegde specificatie van welke Agent Intents gezamenlijk worden georchestreerd en in welke volgorde zij worden uitgevoerd. De specificatie beschrijft daarmee de samenhang van het werk, niet de concrete uitvoering ervan. DOEL Het expliciet en reproduceerbaar vastleggen van de orchestratie die binnen een specifieke Operational Context geldt, zodat duidelijk is welke Agent Intents deelnemen en in welke volgorde zij worden uitgevoerd. LEIDENDE VRAAG Welke Agent Intents worden binnen deze Operational Context georchestreerd en in welke volgorde worden zij uitgevoerd? SAMENSTELLING Een Orchestration Specification bestaat conceptueel uit één of meerdere geordende Agent Intents. De volgorde behoort tot de specificatie. Hoe deze volgorde logisch of technisch wordt vastgelegd, bijvoorbeeld met een volgnummer of een verwijzing naar een voorganger, behoort niet tot het conceptuele model. RELATIES Een Operational Context definieert nul of meerdere Orchestration Specifications. Iedere Orchestration Specification wordt door precies één Operational Context gedefinieerd. Een Orchestration Specification orchestreert één of meerdere Agent Intents. Iedere Agent Intent behoort binnen het huidige conceptuele model tot precies één Orchestration Specification. Iedere Orchestration Specification wordt in haar uitvoering bestuurd door precies één Execution Strategy. Een Execution Strategy kan de uitvoering van nul of meerdere Orchestration Specifications besturen. Een Orchestration Specification kan nul of meerdere keren als Execution worden uitgevoerd. Iedere Execution is de concrete uitvoering van precies één Orchestration Specification. BEPERKINGEN Een Orchestration Specification is geen Execution en beschrijft geen concrete runtime-instantie. Zij specificeert evenmin de interne werking van een Agent Intent. De technische representatie van stappen, volgorde, branching, status en runtime-besturing behoort tot het logisch, functioneel of technisch ontwerp. INVARIANTEN Iedere Orchestration Specification behoort tot precies één Operational Context en bevat minimaal één Agent Intent. De Agent Intents binnen een Orchestration Specification hebben een eenduidige uitvoeringsvolgorde. Iedere Orchestration Specification heeft precies één Execution Strategy. De Operational Context van een Execution is afleidbaar via de Orchestration Specification waarvan die Execution een concrete uitvoering is.
