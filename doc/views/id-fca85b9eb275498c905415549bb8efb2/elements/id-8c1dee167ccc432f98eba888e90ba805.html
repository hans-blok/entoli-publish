operational rule ()
DEFINITIE Een Operational Rule (Operationele regel) is een Rule die voor een specifieke handeling voorschrijft wat tijdens de uitvoering moet worden gedaan, niet mag worden gedaan of onder bepaalde omstandigheden mag worden gedaan. DOEL Een norm zodanig operationaliseren dat deze zonder aanvullende normatieve interpretatie kan worden opgenomen in de instructies voor een concrete uitvoering door een LLM. LEIDENDE VRAAG Wat moet tijdens deze specifieke handeling worden gedaan of nagelaten om overeenkomstig de geldende normen te handelen? RELATIES * **specialisation-of** → `Rule` * Kan een **Normative Rule** operationaliseren. * Is van toepassing binnen een specifieke operationele scope. * Een **Entoli Agent Intent Rule** is een Operational Rule die geldt voor één specifieke Entoli Agent Intent. * Kan als toepasselijke regel worden opgenomen in een Instruction Set. BEPERKINGEN * Een Operational Rule legt geen algemene ontwerpgrondslag vast. * Een Operational Rule introduceert geen nieuwe norm die strijdig is met de Normative Rule die hij operationaliseert. * Een Operational Rule mag niet vereisen dat het uitvoerende LLM eerst zelf een algemene norm moet interpreteren om te bepalen welk gedrag wordt verwacht. * Een Operational Rule geldt alleen binnen de operationele scope waarvoor hij is gedefinieerd. INVARIANTEN * Een Operational Rule beschrijft **wat moet worden gedaan, niet gedaan of toegestaan tijdens een handeling**. * Een Operational Rule is voldoende concreet om als uitvoeringsinstructie te kunnen worden aangeboden. * Wanneer een Operational Rule een Normative Rule operationaliseert, blijft die normatieve herkomst traceerbaar. * Het Instruction Set bevat de toepasselijke Operational Rules die nodig zijn voor de betreffende Execution.
