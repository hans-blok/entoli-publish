DEFINITIE Een Intent Instruction (Intent-instructie) is een geordende, normatieve aanwijzing die beschrijft hoe een Agent Intent inhoudelijk door een LLM moet worden uitgevoerd. Een Intent Instruction behoort tot precies één Agent Intent en is onafhankelijk van een concrete Execution. DOEL De Intent Instruction bestaat om de interne professionele werkwijze van een Agent Intent expliciet, overdraagbaar en reproduceerbaar te maken, zonder deze werkwijze te vermengen met orchestration of execution-specifieke context. LEIDENDE VRAAG Welke inhoudelijke handeling moet het LLM op dit punt in de uitvoering van deze Agent Intent verrichten? RELATIES Een Agent Intent heeft één of meer Intent Instructions. Een Intent Instruction behoort tot precies één Agent Intent. Intent Instructions van een Agent Intent hebben onderling een expliciete uitvoeringsvolgorde. Een Agent Intent stuurt de samenstelling van een Instruction Set voor een concrete Execution; de Intent Instructions vormen daarbij de stabiele, intent-specifieke werkwijze. BEPERKINGEN Een Intent Instruction is geen Execution Step Specification: die specificeert dat een Agent Intent binnen een Orchestration wordt aangeroepen, niet hoe die Intent inhoudelijk wordt uitgevoerd. Een Intent Instruction is geen Instruction Set: het Instruction Set is de execution-specifieke samenstelling van toepasselijke instructies, regels, semantische kennis en context. Een Intent Instruction is geen Rule: een Rule begrenst of normeert gedrag; een Intent Instruction schrijft een handeling binnen de werkwijze voor. Een Intent Instruction bevat geen execution-specifieke waarden of runtimeconfiguratie. Een Intent Instruction vertegenwoordigt één betekenisvolle handeling en is niet slechts een technisch tekstfragment van een prompt. INVARIANTEN Iedere Intent Instruction behoort tot precies één Agent Intent. Iedere Intent Instruction heeft een expliciete positie in de uitvoeringsvolgorde van die Agent Intent. Iedere Agent Intent heeft ten minste één Intent Instruction. De verzameling Intent Instructions van een Agent Intent beschrijft de inhoudelijke werkwijze zonder afhankelijk te zijn van een concrete Execution, Orchestration of LLM-configuratie. De betekenis van een Intent Instruction blijft gelijk ongeacht de wijze waarop zij technisch in een prompt of Instruction Set wordt gerepresenteerd.
