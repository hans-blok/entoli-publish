reasoning regime ()
DEFINITIE Een Reasoning Regime (Redeneerregime) bepaalt de mate van cognitieve vrijheid die een LLM heeft bij het uitvoeren van een Agent Intent. Het bepaalt hoeveel ruimte het LLM krijgt om te exploreren, interpreteren en synthetiseren binnen de grenzen van de uitvoering. DOEL Expliciet maken hoeveel cognitieve vrijheid passend is voor een Agent Intent, zodat exploratief werk ruimte kan krijgen voor hypothesevorming en alternatieven, terwijl afleidend en transformerend werk kan worden begrensd tot wat uit de beschikbare betekenis en regels verantwoord volgt. LEIDENDE VRAAG Hoeveel cognitieve vrijheid mag het LLM gebruiken bij het uitvoeren van deze Agent Intent? RELATIES Een Agent Intent heeft precies één Reasoning Regime. Een Reasoning Regime kan van toepassing zijn op nul of meer Agent Intents. Een Reasoning Regime heeft precies één van de volgende positiewaarden: * Explorative — het LLM heeft ruime cognitieve vrijheid om mogelijkheden te onderzoeken, hypothesen te formuleren, alternatieven te identificeren en mogelijke interpretaties te vormen. * Interpretive — het LLM heeft ruimte om beschikbare betekenis te interpreteren, informatie met elkaar in verband te brengen en beredeneerde conclusies te vormen binnen een vastgesteld vraagstuk of doel. * Constrained — het LLM redeneert binnen expliciet gegeven betekenis, regels en grenzen; interpretatie is alleen toegestaan voor zover deze noodzakelijk is om de bedoelde analyse, beoordeling of transformatie uit te voeren. * Deterministic — het LLM leidt het resultaat af met minimale interpretatievrijheid; de gegeven betekenis, regels en transformatievoorwaarden bepalen het toegestane resultaat voor zover mogelijk. Een Reasoning Regime vormt een grondslag voor Model Assignment. Een Model Assignment realiseert het vereiste Reasoning Regime door een passende model- en uitvoeringsconfiguratie toe te wijzen. BEPERKINGEN Een Reasoning Regime is geen Development Phase en geeft niet aan waar werk zich in een ontwikkelproces bevindt. Een Reasoning Regime is geen Source Regime en bepaalt niet welke bronnen tijdens een uitvoering mogen of moeten worden gebruikt. Een Reasoning Regime is geen Task Regime en bepaalt niet welk soort taak wordt uitgevoerd. Een Reasoning Regime is geen Model Assignment en specificeert geen model, thinking effort, tokenlimieten of temperature. Een Reasoning Regime beschrijft geen mate van intelligentie, kwaliteit of benodigde redeneerinspanning. Een strikter regime kan juist veel redeneerinspanning vereisen. INVARIANTEN Iedere Agent Intent die door een LLM wordt uitgevoerd heeft precies één Reasoning Regime. De positiewaarden vormen een ordening van meer naar minder toegestane cognitieve vrijheid: Explorative, Interpretive, Constrained, Deterministic. Een lagere cognitieve vrijheid betekent niet dat minder redeneerinspanning nodig is. Een Deterministic Reasoning Regime minimaliseert interpretatievrijheid, maar sluit complexe reasoning niet uit. Het Reasoning Regime blijft onafhankelijk van de technische mogelijkheden en configuratieparameters van een specifiek LLM. Een Model Assignment moet het vereiste Reasoning Regime realiseren zonder de semantische betekenis ervan te wijzigen.
